Humanoid Robot vs. Virtual Agent

Comparing a Physical Humanoid Social Robot and a Screen-Based Virtual Agent in AI-Supported Self-Regulated Environmental Learning: A Mixed-Methods Study with an Active Control Condition among Middle School Students

Project period2026–2029
Funding bodyTÜBİTAK · 3501 Career Development Program
Principal investigatorHüseyin Ateş
Research overview

Research rationale.

This funded project examines AI-supported self-regulated environmental learning by comparing a physical humanoid social robot with a screen-based virtual agent. The project title specifies a mixed-methods design and an active control condition involving middle school students.
